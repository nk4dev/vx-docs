# `vx3 api`

ローカルのヘルパー API サーバーを起動します。EVM を実行するわけでは**ありません**。`vx.config.json` に設定された RPC と通信する小さな HTTP API を公開します。`vx3 node` は非推奨の隠しエイリアスです。

```bash
vx3 api                    # http://127.0.0.1:8545
vx3 api --port 8000
vx3 api --host 0.0.0.0
vx3 api --debug            # /debug でデバッグページを配信
vx3 api --allow-origin http://localhost:5173   # フロントエンドの開発サーバーから /api/pay を呼べるようにする
```

| フラグ | デフォルト | 説明 |
| --- | --- | --- |
| `--host <host>` | `127.0.0.1` | バインドするインターフェース。 |
| `--port <port>` | `8545` | 待ち受けるポート（数値でない場合は `8545` にフォールバック）。 |
| `--debug` | オフ | `/debug` ページを有効にします。 |
| `--env <name>` | `development` | デバッグ出力に表示される環境ラベル。 |
| `--chains <json>` | — | デバッグ出力に表示されるチェーン一覧（JSON）。不正な JSON は警告を出して無視されます。 |
| `--allow-origin <origin>` | — | `POST /api/pay` の呼び出しを追加で許可するオリジン。複数回指定でき、カンマ区切りも使えます。 |

> **ポート 8545 は Hardhat と Anvil のデフォルトでもあり**、`vx3 rpc init` が書き出す RPC のポートでもあります。すでにローカルノードが動いている場合は、`--port` で別のポートを指定してください。

## エンドポイント

| エンドポイント | メソッド | 説明 |
| --- | --- | --- |
| `/api` | GET | ウェルカムメッセージ。 |
| `/api/block` | GET | 設定された RPC の最新ブロック番号（`{ "blockNumber": n }`）。 |
| `/api/accounts` | GET | 生成された開発用アカウント（アドレスと表示用の残高）。 |
| `/api/pay` | POST | 支払いを送信します。ボディは `{ "to", "amountEth", "rpcUrl"? }`。 |
| `/events` | GET | ブロックの更新をリアルタイムに配信する SSE ストリーム。 |
| `/debug` | GET | RPC セレクター付きのデバッグページ。`--debug` を指定したときのみ配信され、それ以外は `404` を返します。 |

`/api/pay` はリクエストボディで秘密鍵を受け付けません。サーバー側の環境変数 `PRIVATE_KEY` で署名し、未設定の場合は開発用アカウント `(0)` で署名します。

### `/api/pay` を呼び出せるオリジン

このエンドポイントは資金を動かすため、他のオリジンからのブラウザリクエストは `403` で拒否されます。受け付けるのは次の場合です。

- `Origin` ヘッダーがない（curl やサーバー側のコード）
- `Origin` がサーバー自身である — ループバックアドレスにバインドしている場合、サーバーのポート上の `localhost`、`127.0.0.1`、`[::1]` はすべて同じオリジンとして扱われます
- `Origin` が `--allow-origin` で指定されている

`403` のレスポンスには、追加すべきフラグ（例: `--allow-origin http://localhost:5173`）が示されます。

### フロントエンドの開発サーバーから使う

React と Vue のテンプレートは `/api` を `http://127.0.0.1:8545` にプロキシします（環境変数 `VX3_API_URL` で変更できます）。ブラウザは開発サーバーのオリジンを送るため、明示的に許可してください。

```bash
vx3 api --port 8600 --allow-origin http://localhost:5173
VX3_API_URL=http://127.0.0.1:8600 npm run dev
```

ガスのデータ（`/api/gas`）やサーバーと RPC の状態（`/api/status`）が必要な場合は、[`vx3 dash`](/ja/docs/commands/dashboard) を使用してください。

起動時に、Hardhat の公開ニーモニック `test test ... junk` から導出した 10 個の決定的な開発用アカウントを表示します。ローカルでのテストには便利ですが、接続先の RPC 自体が新規のローカルノードである場合にしか残高はありません。**これらの鍵をパブリックネットワークで絶対に使用しないでください。**
