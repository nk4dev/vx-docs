# `vx3 nft mint`

Mint an NFT: `vx3 nft mint <contractAddress> [--to <address>] [--id <tokenId>] [--uri <tokenURI>] [--fn <functionName>] [--rpc <url>] [--key <privateKey>] [--json]`. `mint` is the only subcommand.

```bash
export PRIVATE_KEY='0x...'
vx3 nft mint 0xContractAddress \
  --to 0xRecipientAddress \
  --uri ipfs://... \
  --rpc http://127.0.0.1:8545
```

`--to` defaults to the signer's own address. `--rpc` / `--key` (short: `-r` / `-k`) behave as in [`vx3 pay`](/docs/commands/pay): the RPC falls back to `vx.config.json`, and the key falls back to `PRIVATE_KEY`.

## Choosing the mint function

The default ABI covers common ERC-721 signatures, chosen from the flags you pass:

| Flags | Calls |
| --- | --- |
| `--uri` only | `safeMint(address,string)` |
| `--id` only | `mint(address,uint256)` |
| `--id` and `--uri` | Error — the default ABI has no `(address,uint256,string)` overload. |
| neither | Error — provide one of them. |

Pass `--fn <name>` to call a custom function instead; `to`, then `--id` and `--uri` (when given) are passed as its arguments in that order. Custom ABIs are only available from the [SDK](/docs/api/nft-minting).

With `--json`, prints `{ "txHash", "blockNumber" }` (or `{ "error" }`).

## Safety checks

- The contract address must hold contract code on the target network. Otherwise the command fails with `No contract found at <address>` instead of sending a transaction that mints nothing.
- A flag that needs a value fails with `Missing value for <flag>` when the value is missing — it never falls back to a default RPC, key or recipient.
