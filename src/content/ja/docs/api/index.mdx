# vx3 API リファレンス

自分のコードから `vx3` を使うために必要な情報をまとめています。CLI については[コマンドリファレンス](/ja/docs/commands)を参照してください。

## インストール

```bash
npm install vx3
```

`react` と `react-dom` は任意の peer dependency です。React コンポーネントやフックを使う場合にだけインストールしてください。それ以外は React なしで動作します。
