# `vx3 ipfs`

CID を指定してコンテンツを取得します: `vx3 ipfs fetch <cid> [gatewayUrl]`。サブコマンドは `fetch` のみです。

```bash
vx3 ipfs fetch <cid>
vx3 ipfs fetch <cid> https://ipfs.io
```

`gatewayUrl` を省略すると、`vx.config.json` の `"type": "ipfs"` エントリからゲートウェイが決まります（`gateway` の URL、なければ `api` の host / port / protocol）。`vx3 rpc init` は、`https://ipfs.io` を指すデフォルトのエントリを書き出します。

テキストと JSON のレスポンスはそのまま表示され、バイナリコンテンツはバイト単位のサイズのみが表示されます。
