# `vx3 dash`

リアルタイム開発ダッシュボードを開きます。

```bash
vx3 dash                   # http://127.0.0.1:4000
vx3 dash --port 5000       # ポートを指定
vx3 dash --host 0.0.0.0    # すべてのインターフェースにバインド
vx3 dash --open            # ブラウザで自動的に開く
```

> **注意:** `--host 0.0.0.0` を指定すると、ダッシュボードの `/api/*` エンドポイントがネットワーク全体に公開されます。認証はないため、信頼できるネットワーク上でのみ使用してください。

## ダッシュボードのエンドポイント

| エンドポイント | メソッド | 説明 |
| --- | --- | --- |
| `/` | GET | ダッシュボードの HTML |
| `/api/status` | GET | サーバーと RPC の状態 |
| `/api/block` | GET | 最新のブロック番号 |
| `/api/gas` | GET | EIP-1559 のガス代データ |
| `/api/rpc` | GET | RPC 設定の一覧 |
| `/events` | GET | SSE ストリーム（ブロックとガス、4 秒ごと） |
