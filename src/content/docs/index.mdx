# Introduction

`vx3` is a developer-first toolkit for building, testing, and shipping Web3 applications. It works as a CLI and as an SDK you can import into your own code, and bundles:

- Multi-chain support (ethers.js v6)
- A local helper API server for block/gas/payment proxying
- A real-time developer dashboard (`vx3 dash`)
- **VXC**, an in-house custom Solidity compiler
- Payment and NFT-minting helpers, with a ready-made React component and hooks
- Hardhat, React, and Vue project scaffolding
- IPFS pin/fetch helpers
- RPC endpoint management

## What you'll need

- [Node.js](https://nodejs.org/en/download/) version 18 or above
- npm / pnpm / yarn / bun (any one of them)

## Install

```bash
npm install -g vx3
```

You can also add it as a project dependency (`npm install vx3`) or run it without installing via `npx vx3 <command>`.

To build from source instead:

```bash
git clone https://github.com/nk4dev/vx
cd vx
bun i
bun run build
bun link        # exposes the `vx3` binary globally
```

## Try it out

Scaffold a new project and configure an RPC endpoint:

```bash
vx3 create
vx3 rpc init
```

Start the local helper API server:

```bash
vx3 api --debug
```

Or open the real-time developer dashboard instead:

```bash
vx3 dash --open
```

Check current gas fees on your configured RPC:

```bash
vx3 gas
```
