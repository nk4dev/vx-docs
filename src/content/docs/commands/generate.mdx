# `vx3 generate`

Generate a framework template (react, vue).

```bash
vx3 generate list               # list available templates
vx3 generate template/react my-app
vx3 generate template/vue my-app
```

Both scaffold a Vite + TypeScript demo app wired up with the `<Payment />` component and hooks — see the [React components & hooks](/docs/api/react-components) reference for how to use them in your own code.
