# vx3 API Reference

Everything you need to use `vx3` from your own code. For the CLI, see the [Command Reference](/docs/commands).

## Install

```bash
npm install vx3
```

## Using the SDK from code

### TypeScript / ESM

```ts
import vx from 'vx3';

const rpc = vx.getRpcUrl();
const block = await vx.getBlockNumber(rpc);
const gas = await vx.getGasFees(rpc);
```

### CommonJS

```js
const vx = require('vx3').default;
vx.getGasFees('http://127.0.0.1:8545').then(console.log);
```

## Sending Payments Programmatically

```ts
import vx from 'vx3';

await vx.payment.sendPayment({
  rpcUrl: 'http://127.0.0.1:8545',
  privateKey: process.env.PRIVATE_KEY!,
  to: '0xRecipientAddress',
  amountEth: '0.01',
});
```

## Minting NFTs Programmatically

```ts
import vx from 'vx3';

await vx.mintNFT({
  rpcUrl: 'http://127.0.0.1:8545',
  privateKey: process.env.PRIVATE_KEY!,
  contractAddress: '0xContractAddress',
  to: '0xRecipientAddress',
  tokenURI: 'ipfs://...',
});
```

By default this resolves to a `mint`/`safeMint`-style call based on whether `tokenId` and/or `tokenURI` are given; pass `functionName` to target a custom function, and `abi` to override the ABI used.

## React components & hooks

`vx3` ships a ready-made `<Payment />` component plus hooks, generated into your project by `vx3 setup react` or `vx3 generate` (see the [Command Reference](/docs/commands#vx3-generate--vx3-setup-react-scaffolding-a-frontend)):

```tsx
import { Payment } from 'vx3';

<Payment
  to="0xRecipientAddress"
  amount="0.01"
  mode="wallet" // "wallet" uses window.ethereum, "api" posts to /api/pay
  onSuccess={(result) => console.log(result.txHash)}
  onError={(error) => console.error(error)}
/>;
```

For custom UI, use the underlying hooks directly:

```tsx
import { usePayment, usePaymentStatus, usePaymentDialog } from 'vx3';

const { pay, state } = usePayment();
await pay({ to: '0xRecipientAddress', amount: '0.01', mode: 'wallet' });
```

`usePaymentStatus` exposes the current `idle | pending | success | error` lifecycle state, and `usePaymentDialog` returns `{ isOpen, open, close, toggle }` for wiring up a payment modal.
