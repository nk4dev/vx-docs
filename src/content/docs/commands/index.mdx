# vx3 CLI Reference

This section covers installing `vx3` and every command its CLI exposes, one page per command (or closely related group of commands).

## Prerequisites

- Node.js 18 or higher
- npm / pnpm / yarn / bun (or any one of them)

## Installation

### Using as a global CLI

```bash
npm install -g vx3
```

### Add as a dependency to your project

```bash
npm install vx3
```

### One-off execution (no installation required)

```bash
npx vx3 <command>
```

### Building from source

```bash
git clone https://github.com/nk4dev/vx
cd vx
bun i
bun run build
bun link        # exposes the `vx3` binary globally
```

## Command reference

| Command | Description | Details |
| --- | --- | --- |
| `vx3 init [name]` | Initialize a new project with default settings. | [Project setup](/docs/commands/project) |
| `vx3 create [name]` | Scaffold a new project (interactive when `name` is omitted). | [Project setup](/docs/commands/project) |
| `vx3 api` | Start the local helper API server on port 8545. | [`vx3 api`](/docs/commands/api-server) |
| `vx3 dash` | Open the real-time developer dashboard (port 4000). | [`vx3 dash`](/docs/commands/dashboard) |
| `vx3 setup hardhat\|react` | Add Hardhat or a React frontend to the current project. | [`vx3 setup`](/docs/commands/setup) |
| `vx3 rpc init\|list` | Manage or query RPC endpoints from `vx.config.json`. | [`vx3 rpc`](/docs/commands/rpc) |
| `vx3 pay <to> <amount>` | Send a transaction. | [`vx3 pay`](/docs/commands/pay) |
| `vx3 gas` | Estimate gas fees for a transaction. | [`vx3 gas`](/docs/commands/gas) |
| `vx3 ipfs fetch <cid>` | Pin / fetch content via IPFS. | [`vx3 ipfs`](/docs/commands/ipfs) |
| `vx3 generate` | Generate templates (react, vue). | [`vx3 generate`](/docs/commands/generate) |
| `vx3 compile <entry.sol>` | Compile Solidity using the VXC custom compiler. | [`vx3 compile`](/docs/commands/compile) |
| `vx3 nft mint <contract>` | Mint an NFT. | [`vx3 nft`](/docs/commands/nft) |
| `vx3 sol hello` | Solidity helper sample. | [Misc](/docs/commands/misc) |
| `vx3 info` | Display the remote VX platform version. | [Misc](/docs/commands/misc) |
| `vx3 --version`, `-v` | Show SDK version. | [Misc](/docs/commands/misc) |
| `vx3 help` | Show the help screen. | [Misc](/docs/commands/misc) |
