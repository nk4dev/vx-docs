# vx3 API Reference

Everything you need to use `vx3` from your own code. For the CLI, see the [Command Reference](/docs/commands).

## Install

```bash
npm install vx3
```

`react` and `react-dom` are optional peer dependencies: install them only if you use the React component or hooks. Everything else works without React.
