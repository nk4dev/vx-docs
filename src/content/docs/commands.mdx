# vx3 CLI Reference

This page covers installing `vx3` and every command its CLI exposes.

## Prerequisites

- Node.js 18 or higher
- npm / pnpm / yarn / bun (or any one of them)

## Installation

### Using as a global CLI

```bash
npm install -g vx3
```

### Add as a dependency to your project

```bash
npm install vx3
```

### One-off execution (no installation required)

```bash
npx vx3 <command>
```

### Building from source

```bash
git clone https://github.com/nk4dev/vx
cd vx
bun i
bun run build
bun link        # exposes the `vx3` binary globally
```

## Command reference

| Command | Description |
| --- | --- |
| `vx3 init [name]` | Initialize a new project with default settings. |
| `vx3 create [name]` | Scaffold a new project (interactive when `name` is omitted). |
| `vx3 api` | Start the local helper API server on port 8545. It does **not** run an EVM — `/api/block`, `/api/gas`, and `/api/pay` proxy to the RPC in `vx.config.json`. (`vx3 node` is a deprecated alias.) |
| `vx3 dash` | Open the real-time developer dashboard (port 4000). |
| `vx3 setup hardhat\|react` | Add Hardhat or a React frontend to the current project. |
| `vx3 rpc init\|list` | Manage or query RPC endpoints from `vx.config.json`. |
| `vx3 pay <to> <amount>` | Send a transaction. Flags: `--rpc`, `--key`, `--json`. |
| `vx3 gas` | Estimate gas fees for a transaction. Flags: `--rpc`, `--path`, `--json`. |
| `vx3 ipfs fetch <cid>` | Pin / fetch content via IPFS. |
| `vx3 generate` | Generate templates (react, vue). |
| `vx3 compile <entry.sol>` | Compile Solidity using the VXC custom compiler. |
| `vx3 nft mint <contract>` | Mint an NFT. Flags: `--to`, `--id`, `--uri`, `--fn`, `--rpc`, `--key`, `--json`. |
| `vx3 sol hello` | Solidity helper sample. |
| `vx3 info` | Display the remote VX platform version. |
| `vx3 --version`, `-v` | Show SDK version. |
| `vx3 help` | Show the help screen. |

### `vx3 api`: local helper API server

```bash
vx3 api                    # http://127.0.0.1:8545
vx3 api --port 8000
vx3 api --host 0.0.0.0
vx3 api --debug            # serves a debug page at /debug
```

On startup it prints 10 deterministic dev accounts derived from Hardhat's public `test test ... junk` mnemonic — convenient for local testing, but only funded if the RPC you point it at is itself a fresh local node. **Never use these keys on a public network.**

### `vx3 dash`: real-time developer dashboard

```bash
vx3 dash                   # http://127.0.0.1:4000
vx3 dash --port 5000       # custom port
vx3 dash --host 0.0.0.0    # bind to all interfaces
vx3 dash --open            # auto-open in browser
```

> **Note:** `--host 0.0.0.0` exposes the dashboard's `/api/*` endpoints to your whole network. There is no authentication, so only do this on a trusted network.

Dashboard endpoints:

| Endpoint | Method | Description |
| --- | --- | --- |
| `/` | GET | Dashboard HTML |
| `/api/status` | GET | Server + RPC status |
| `/api/block` | GET | Latest block number |
| `/api/gas` | GET | EIP-1559 gas fee data |
| `/api/rpc` | GET | RPC config list |
| `/events` | GET | SSE stream (block + gas, every 4s) |

### `vx3 rpc`: managing RPC endpoints

```bash
vx3 rpc init   # create a starter vx.config.json
vx3 rpc list   # show the configured RPC URL
```

### `vx3 pay`: sending funds from the command line

The private key is read from the `PRIVATE_KEY` environment variable by default. Passing `--key` directly works too, but is discouraged — it can leak via shell history and process listings.

```bash
# bash / zsh
export PRIVATE_KEY='0x...'
vx3 pay 0xRecipientAddress 0.01 --rpc http://127.0.0.1:8545
```

```powershell
# PowerShell
$env:PRIVATE_KEY='0x...'
vx3 pay 0xRecipientAddress 0.01 --rpc http://127.0.0.1:8545
```

### `vx3 compile`: the VXC Solidity compiler

```bash
vx3 compile contracts/Token.sol \
  --out build \
  --optimize --runs 1000 \
  --evm cancun \
  --remap @openzeppelin/=node_modules/@openzeppelin/
```

Artifacts (`<Contract>.json` + `vxc.manifest.json`) are written to `--out` and are deploy-ready.

### `vx3 nft mint`: minting from the command line

```bash
export PRIVATE_KEY='0x...'
vx3 nft mint 0xContractAddress \
  --to 0xRecipientAddress \
  --uri ipfs://... \
  --rpc http://127.0.0.1:8545
```

By default it calls a standard `mint`/`safeMint`-style function on the target contract; pass `--fn` to call a custom function name instead.

### `vx3 generate` / `vx3 setup react`: scaffolding a frontend

```bash
vx3 generate list               # list available templates
vx3 generate template/react my-app
vx3 generate template/vue my-app
```

Or, inside an existing project:

```bash
vx3 setup react
```

Both scaffold a Vite + TypeScript demo app wired up with the `<Payment />` component and hooks — see the [API reference](/docs/api#react-components--hooks) for how to use them in your own code.
