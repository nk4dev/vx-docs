# その他のコマンド

## `vx3 sol hello`

Solidity ヘルパーのサンプルです。

```bash
vx3 sol hello
```

## `vx3 info`

リモートの VX プラットフォームのバージョンを表示します。

```bash
vx3 info
```

## `vx3 --version` / `-v`

SDK のバージョンを表示します。

```bash
vx3 --version
```

## `vx3 help`

ヘルプ画面を表示します。

```bash
vx3 help
```
