# `vx3 setup`

Add Hardhat or a React frontend to the current project: `vx3 setup <hardhat|react>`.

```bash
vx3 setup hardhat
vx3 setup react
```

`vx3 setup react` scaffolds a Vite + TypeScript demo app wired up with the `<Payment />` component and hooks — see the [React components & hooks](/docs/api/react-components) reference for how to use them in your own code.
