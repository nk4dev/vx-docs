# `vx3 init` / `vx3 create`

## `vx3 init [name]`

Create a new project directory from the bundled template. The directory is `name` inside the current directory, or `my-vx-project` when omitted. The command fails if the directory already exists.

```bash
vx3 init
vx3 init my-app
```

`name` must be a plain directory name: absolute paths and `.` / `..` segments are rejected.

## `vx3 create [name]`

Scaffold a new project. Behaves like `vx3 init` when `name` is given; runs an interactive prompt when it's omitted.

```bash
vx3 create
vx3 create my-app
```
