# Misc commands

## `vx3 sol hello`

Solidity helper sample.

```bash
vx3 sol hello
```

## `vx3 info`

Display the remote VX platform version.

```bash
vx3 info
```

## `vx3 --version` / `-v`

Show SDK version.

```bash
vx3 --version
```

## `vx3 help`

Show the help screen.

```bash
vx3 help
```
